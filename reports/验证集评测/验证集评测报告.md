# WattBot 2026 验证集评测报告

验证集完成 **245 / 245** 题的预测，比赛评分器给出的加权总分为 **0.8820**。

## 评测设置

使用 `deepseek-flash`，关闭思考。预测复用论文索引，覆盖 122 份论文和 12,006 个检索块。验证集使用比赛提供的 `input/train_QA.csv`。预测读取题号、题目和答案单位，标准答案由 `input/Score.py` 在预测结束后按题号配对评分。

## 评分结果

| 指标 | 结果 |
| --- | --- |
| 答案值匹配 | 212 / 245（86.5%） |
| 引用 F1 分数 | 0.916 |
| 给出答案 / 标记证据不足 | 237 / 8 |
| 在标准答案为证据不足的题目中正确拒答 | 4 / 5 |

答题用时包含检索、重排、证据组织、模型调用和答案处理。费用按固定高峰单价估算，缓存命中输入、未命中输入和输出每百万词元分别为 0.04 元、2 元和 8 元。
